# VHWuWa Mobile

Bản Việt hóa **Wuthering Waves trên Android** do WAHU phát hành.

## Phiên bản hiện tại

- **VHWuWa Mobile:** `0.2.0-alpha.8`
- **Wuthering Waves hỗ trợ:** `3.7.0`
- **Nội dung Việt hóa:** `3.7.0-R1`
- **Android:** 10 trở lên
- **Quyền cài đặt:** Shizuku
- **Kiểu tên:** Tên Anh hoặc Hán Việt
- **Cách cài:** dùng cơ chế gắn gói riêng, không ghi đè PAK gốc của game

## Tải xuống

- GitHub: https://github.com/WahuVN/VHWuWa-Mobile
- Bản phát hành: https://github.com/WahuVN/VHWuWa-Mobile/releases/tag/v0.2.0-alpha.8
- APK: `VHWuWa-Android-0.2.0-alpha.8-3.7.0-R1.apk`

## Hướng dẫn cài đặt

1. Cập nhật Wuthering Waves Global lên **3.7.0**.
2. Mở game một lần và tải xong toàn bộ tài nguyên cần thiết.
3. Mở Shizuku và khởi động dịch vụ.
4. Cài **VHWuWa Mobile**.
5. Cấp quyền Shizuku khi ứng dụng yêu cầu.
6. Chọn **Tên Anh** hoặc **Hán Việt**.
7. Bấm **Cài Việt hóa**.
8. Mở game và trải nghiệm.

## Cập nhật từ bản cũ

Bản `0.2.0-alpha.8` giữ cùng mã ứng dụng và chữ ký với `alpha.7`, vì vậy có thể **cài đè trực tiếp** để cập nhật.
