# VHWuWa Mobile

Bản Việt hóa Wuthering Waves dành cho Android do WAHU phát hành.

## Bản công khai hiện tại

- Mobile: `0.2.0-alpha.7`
- Game hỗ trợ: `Wuthering Waves Global 3.7.0`
- Content Việt hóa: `3.7.0-R1`
- Android: 10+ (`minSdk 29`)
- Cần Shizuku để cài patch an toàn vào thư mục game.

Tải APK tại trang **Releases** của repository này.

## Cách cài

1. Cài hoặc cập nhật Wuthering Waves Global lên đúng phiên bản được hỗ trợ.
2. Mở game và tải hoàn tất Resource.
3. Mở Shizuku và khởi động dịch vụ.
4. Cài VHWuWa Mobile.
5. Cấp quyền Shizuku khi app yêu cầu.
6. Chọn bản dịch **Tên Anh** hoặc **Hán Việt**.
7. Bấm **Cài Việt hóa**, sau đó mở game.

## Cập nhật app

Các bản Mobile kế tiếp giữ cùng application ID và chữ ký phát hành hiện tại để có thể cài đè trực tiếp lên bản trước.

## An toàn

- App dùng custom mount riêng.
- Không ghi đè PAK gốc của game.
- Mỗi release có file SHA256 để kiểm tra toàn vẹn.
- Repo này chỉ dùng để phát hành Mobile công khai; source/dữ liệu làm việc nội bộ không được phát hành tại đây.
