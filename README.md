# VHWuWa Mobile

Bản Việt hóa Wuthering Waves dành cho Android do WAHU phát hành.

## Bản công khai hiện tại

- Mobile: `0.2.0-alpha.8`
- Game hỗ trợ: `Wuthering Waves Global 3.7.0`
- Content Việt hóa: `3.7.0-R1`
- Android: 10+ (`minSdk 29`)
- Cần Shizuku để cài patch an toàn vào thư mục game.

## Download

- Release: https://github.com/WahuVN/VHWuWa-Mobile/releases/tag/v0.2.0-alpha.8
- APK: `VHWuWa-Android-0.2.0-alpha.8-3.7.0-R1.apk`
- SHA256 đi kèm trong release để kiểm tra toàn vẹn.

## Cách cài

1. Cập nhật Wuthering Waves Global lên 3.7.0 và tải xong Resource.
2. Mở Shizuku và khởi động dịch vụ.
3. Cài VHWuWa Mobile.
4. Cấp quyền Shizuku khi app yêu cầu.
5. Chọn bản dịch **Tên Anh** hoặc **Hán Việt**.
6. Bấm **Cài Việt hóa**, sau đó mở game.

## An toàn

- App dùng custom mount riêng.
- Không ghi đè PAK gốc của game.
- Mỗi release có SHA256.
- Repo này chỉ dùng để phát hành Mobile công khai.
